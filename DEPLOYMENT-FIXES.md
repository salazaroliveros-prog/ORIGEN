# Vercel deployment fix summary — ORIGEN ConstructERP

## Issues fixed

### 1. Sensitive data exposed in .env file

**Problem:** The root `.env` file contained sensitive Vercel and GitHub tokens that were committed to the repository:

- `TOKEN_VERCEL=[Tu token de Vercel aquí]`
- `TOKEN_GITHUB=[Tu token de GitHub aquí]`
- `GOOGLE_CLIENT_ID=893831571998-0gddqv63u8lain61j1svpdfs4pcm44rh.apps.googleusercontent.com`

**Solution:** Removed these sensitive values from `.env`. They should be configured via Vercel Dashboard.

**Action taken:** Deleted lines 23 to 24 (`TOKEN_VERCEL`, `TOKEN_GITHUB`) and line 26 (`GOOGLE_CLIENT_ID`) from `.env`.

### 2. Environment variables not configured in Vercel Dashboard

**Problem:** While `.env.local` has all the Firebase and app configuration variables, they need to be explicitly set in Vercel's Environment Variables settings.

**Variables that must be set in Vercel Dashboard > Settings > Environment Variables:**

**Required (required for production):**

- `NEXT_PUBLIC_FIREBASE_PROJECT_ID`
- `NEXT_PUBLIC_FIREBASE_API_KEY`
- `NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN`
- `NEXT_PUBLIC_FIREBASE_APP_ID`
- `NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET`
- `NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID`
- `NEXT_PUBLIC_FIREBASE_MEASUREMENT_ID`
- `NEXT_PUBLIC_FIRESTORE_DATABASE_ID`

**Optional but recommended:**

- `NEXT_PUBLIC_FIREBASE_VAPID_KEY`
- `GEMINI_API_KEY` (already configured in `.env.local`: `***MASKED***`)
- `PRIMARY_ADMIN_EMAIL` (`salazaroliveros@gmail.com`)
- `ALLOWED_ORIGINS` (`http://localhost:3000,https://origen-one-kohl.vercel.app`)
- `NEXT_PUBLIC_APP_URL` (`http://localhost:3000` or `https://origen-one-kohl.vercel.app`)

**Action needed:** Go to Vercel Dashboard → Settings → Environment Variables and add all variables from `.env.local`.

### 4. Vercel OIDC token

**Current:** `.env.local` line 32 has `VERCEL_OIDC_TOKEN` which was generated by Vercel CLI.

**Status:** This token is used for OIDC authentication with Vercel. If using the deploy script (`scripts/deploy.js`), you need to set the `VERCEL_TOKEN` environment variable separately.
