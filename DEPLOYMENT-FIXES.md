## Deployment Instructions

### Step 1: Configure Vercel Environment Variables
1. Go to https://vercel.com/dashboard
2. Select your project "ORIGEN" (or create it if needed)
3. Navigate to **Settings > Environment Variables**
4. Click "Add Variable" and add all variables from `.env.local`
5. Make sure to set them for **Production, Preview, and Development** environments
6. Click "Save"

### Step 2: Trigger a New Deployment
1. Go to the "Deployments" tab
2. Click "New Deployment"
3. Select "Git" as the source
4. Choose the main branch
5. Click "Deploy"

### Step 3: Verify Deployment
1. Once deployed, visit your Vercel URL (e.g., `https://origen-one-kohl.vercel.app`)
2. Run the verification script to check environment variables:
   ```
   node scripts/verify-vercel-env.js
   ```
   (This needs to be deployed as an API route first, or check the Vercel logs)

3. Test Firebase authentication and other features

### Step 4: Optional - Use Deploy Script
If you want to use the deploy script:
```
VERCEL_TOKEN=your_vercel_token npm run deploy
```
Or use the CLI:
```
vercel deploy --confirm
```
