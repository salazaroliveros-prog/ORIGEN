🔐 ORIGEN ERP - App Check Debug Token

Esta página genera un token de depuración para Firebase App Check. Copia el token y agrégalo a tu archivo .env.local como NEXT_PUBLIC_FIREBASE_APP_CHECK_DEBUG_TOKEN.

Haciendo clic en "Generar Token"...

📋 Instrucciones:

  1. Haz clic en "Generar Token de Depuración"
  2. Copia el token que aparece en la caja gris
  3. Edita tu archivo .env.local y agrega:
  4. NEXT_PUBLIC_FIREBASE_APP_CHECK_DEBUG_TOKEN=tu-token-aquí
  5. Guarda el archivo y ejecuta: node scripts/setup-final.mjs
