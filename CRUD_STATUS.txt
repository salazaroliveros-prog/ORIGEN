CASOS DE USO
────────────

1️⃣  Constructor en obra (sin WiFi)
    • Crea proyecto → se guarda localmente
    • Agrega gastos → cola de sincronización
    • Registra asistencia → localStorage
    • Vuelve a oficina → todo sincroniza automáticamente

2️⃣  Gerente en oficina
    • Ve proyectos en tiempo real desde Firebase
    • Actualiza presupuesto → instantáneamente
    • Otro usuario ve cambios inmediatamente

3️⃣  Múltiples usuarios colaborando
    • Usuario A crea proyecto (offline)
    • Usuario B ve proyecto cuando User A sincroniza
    • Cambios se propagan a todos en tiempo real

CÓMO USAR
─────────

Importar el hook principal:
import { useProjectData } from '@/lib/hooks/useProjectData';

const {
  projects,        // Lee proyectos en tiempo real
  createProject,   // Crear nuevo proyecto
  updateProject,   // Actualizar proyecto
  archiveProject,  // Eliminar (archivos)
  expenses,        // Lee gastos en tiempo real
  addExpense,      // Crear gasto
  updateExpense,   // Actualizar gasto
  deleteExpense,   // Eliminar gasto
} = useProjectData(companyId, userId, role);

Usar en componente:
async function handleSave(data) {
  const success = await createProject(data);
  if (success) console.log('✅ Guardado en Firebase');
}

Para almacenamiento local:
import { saveOfflineData, loadOfflineData } from '@/lib/offlineStorage';

saveOfflineData('myData', { foo: 'bar' });
const data = loadOfflineData('myData', {});
